# Distributed-File-System

Java で実装した簡単な分散ファイルシステムです。
ターミナルでファイルサーバーを起動し、別のターミナルからクライアントを起動して、サーバー上のファイルを開く、読む、書く、閉じる操作を行います。

## 必要なツール

このプロジェクトをビルド、実行するには、以下のツールをインストールしておく必要があります。

- Java Development Kit (JDK)
- GNU Make

`java`、`javac`、`make` コマンドが使えることを確認してください。

```bash
java -version
javac -version
make --version
```

## ビルド方法

Makefile を使ってクライアントとサーバーの `.class` ファイルを作成します。
生成された `.class` ファイルは `build/classes` に出力されます。

```bash
make client
```

```bash
make server
```

クライアントとサーバーの両方をまとめてビルドする場合は、以下を実行します。

```bash
make all
```

ビルド結果を削除する場合は、以下を実行します。

```bash
make clean
```

## 実行方法

まず、1つ目のターミナルでファイルサーバーを起動します。

```bash
make run-server
```

次に、別のターミナルでクライアントを起動します。

```bash
make run-client
```

サーバーは `12345` 番ポートで待ち受けます。
クライアントは `localhost:12345` に接続します。

## クライアントの操作

クライアントを起動すると、コマンド入力を待ち受けます。

使用できる主なコマンドは以下です。

```text
open <ファイル名> <モード>
read <ファイル名>
write <ファイル名> <内容>
close <ファイル名>
exit
```

ファイルを開くときは、ファイル名とモードを指定します。

```text
open sample.txt READ_WRITE
```

指定できるモードは以下です。

- `READ_ONLY`: 読み込み専用
- `WRITE_ONLY`: 書き込み専用
- `READ_WRITE`: 読み書き両用

ファイルの内容をクライアントからサーバーへ書き込む例です。

```text
open sample.txt READ_WRITE
write sample.txt hello
close sample.txt
```

`close` すると、クライアント側で保持している内容がサーバー側のファイルに保存されます。
サーバー上のファイルは `server_storage` ディレクトリに保存されます。

## 仕様

- サーバーは複数のクライアント接続を受け付けます。
- クライアントはサーバー上のファイルを `open` してから `read`、`write`、`close` します。
- クライアントはファイルを開いたときに、サーバーから取得した内容をローカルのキャッシュに保持します。
- `WRITE_ONLY` または `READ_WRITE` で開いたファイルは、`close` 時にサーバーへ書き戻されます。
- 複数のクライアントが同じファイルを順番に書き込んだ場合、最後に書き戻されたクライアントの内容がサーバー上のファイルに反映されます。
- 書き込み可能なモードで開かれているファイルにはロックがかかるため、他のクライアントが同じファイルを同時に書き込み可能なモードで開くことはできません。
- `READ_ONLY` で開いたファイルは読み込み専用で、`write` することはできません。
- 不正なファイルパスとして `..` を含むパスは拒否されます。
